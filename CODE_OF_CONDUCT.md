# Code of Conduct

## Our commitment

We want this project to be useful, technical, welcoming, and safe for contributors with different levels of experience.

## Expected behavior

- Be respectful and constructive.
- Critique implementations, documentation, or proposals rather than people.
- Explain technical disagreements with evidence when practical.
- Keep discussions focused on the project.
- Assume good intent while remaining precise about impact.

## Unacceptable behavior

- Harassment, personal attacks, threats, or discriminatory behavior.
- Deliberate disruption of issues, pull requests, or releases.
- Publishing private information without permission.
- Malicious changes disguised as contributions.

## Enforcement

Project maintainers may edit, close, or remove contributions that violate this code of conduct and may restrict participation when necessary to protect the project.

For sensitive reports, use the process described in `SECURITY.md`.
