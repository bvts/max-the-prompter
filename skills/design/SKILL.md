# /design

Read `.agents/skills/max-prompter/SKILL.md`.

If installed, prefer Impeccable for design direction and refinement. Useful current command families include `/impeccable`, `/shape`, `/audit`, `/critique`, `/animate`, `/bolder`, `/colorize`, `/delight`, `/layout`, `/overdrive`, `/quieter`, `/typeset`, `/adapt`, `/clarify`, `/distill`, `/harden`, `/onboard`, `/optimize`, `/polish`, `/document`, `/extract`, `/generate`, `/init`, and `/live`.

For React projects:
- consider Motion for React for meaningful interactive/layout/scroll animation
- consider KokonutUI for suitable React/Tailwind components
- consider Bklit UI for suitable charts/data visualization
- use shadcn/Radix/project-native primitives as appropriate
- avoid duplicating component systems unnecessarily

Always establish:
- visual direction
- typography
- spacing
- color roles
- surface hierarchy
- component grammar
- states
- responsive behavior
- motion language
- accessibility

Then verify the rendered result in a browser when tooling allows.
