# /spec

Read `.agents/skills/max-prompter/SKILL.md` first.

Prefer an installed `spec-driven-development` skill from `addyosmani/agent-skills` when available.

Produce a specification covering:
- executive brief
- goals and non-goals
- users/actors
- requirements by priority
- flows
- architecture boundaries
- data and interfaces
- UX/UI where applicable
- security/accessibility/performance where applicable
- edge cases
- acceptance criteria
- verification plan
- implementation boundaries

Persist a project spec in the repository's existing documentation convention, or use `SPEC.md` when no convention exists.
